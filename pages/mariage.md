
# Mariage

\[Mirage WL], \[2025]. Tous droits réservés. Toute reproduction, même partielle, est interdite sans autorisation écrite préalable.

Pour garantir la bonne organisation de votre union, merci de respecter les démarches suivantes. Les conditions du mariage (âge, liens de parenté, témoins) sont dans le [Code civil](code-civil.md).

## 1. Prendre contact avec le Gouvernement

Vous devez contacter le Gouvernement **au moins 1 semaine à l'avance** afin de convenir d'une date pour la cérémonie officielle.

{% hint style="info" %}
Contact : le numéro du Gouvernement.
{% endhint %}

## 2. Célébration du mariage civil

Le mariage civil est célébré **dans les locaux du Gouvernement**, par un membre dûment habilité à officier.

{% hint style="warning" %}
Seule cette cérémonie est reconnue officiellement.
{% endhint %}

## 3. Optionnel : la cérémonie symbolique

Après le mariage civil, vous pouvez organiser une cérémonie plus personnelle :

* **Religieuse** : à l'église, avec un pasteur.
* **Laïque** : dans le lieu de votre choix, avec la personne de votre choix.

{% hint style="danger" %}
Ces cérémonies sont symboliques et n'ont aucune valeur légale au regard du Gouvernement.
{% endhint %}
