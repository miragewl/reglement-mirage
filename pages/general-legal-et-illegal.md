<h2 align="center">2. RÈGLES VÉHICULES</h2>

***

{% columns %}
{% column valign="middle" %}

<h4 align="center">Règles générales</h4>
{% endcolumn %}

{% column %}

* Une course-poursuite doit durer au minimum 5 minutes avant la mise en place d’un plan (mule, planque, fuite organisée, etc.).
* Il est interdit de transporter une personne dans un véhicule en la portant lorsqu’il n’y a plus de place disponible.
* Seuls les coffres de véhicules capables d’accueillir une personne peuvent être utilisés.
* Il est interdit de placer quelqu’un dans le coffre d’un véhicule inadapté (buggy, moto, quad, etc.).
* Une personne dans le coma doit obligatoirement être transportée **dans le coffre d’un véhicule**, jamais portée. **Un véhicule par personne dans le coma.**
* Le PIT est strictement interdit. En cas de PIT involontaire, reprenez la poursuite de manière fair-play.
* Monter ou descendre plus d’une marche en véhicule est interdit.
* Il est interdit d’emprunter des chemins ou raccourcis inaccessibles à vos poursuivants.
  {% endcolumn %}
  {% endcolumns %}

***

{% columns %}
{% column valign="middle" %}

<h4 align="center">Véhicules et actions illégales</h4>
{% endcolumn %}

{% column %}

* Les véhicules super-sportifs sont interdits pour toute activité illégale.
* Les véhicules d'import VIP sont interdits dans l'illégal, **sauf** ceux qui portent l'étiquette rose « **Illégal** » à la concession et sur la boutique, qui sont autorisés.
  {% endcolumn %}
  {% endcolumns %}

***

{% columns %}
{% column valign="middle" %}

<h4 align="center">Off-road</h4>
{% endcolumn %}

{% column %}

* L’off-road est réservé aux véhicules adaptés.
* Traverser brièvement un chemin de terre ou une zone herbeuse est toléré, mais les abus sont sanctionnables.
  {% endcolumn %}
  {% endcolumns %}

***

{% columns %}
{% column valign="middle" %}

<h4 align="center">Motos et poursuites</h4>
{% endcolumn %}

{% column %}

* Les motos sont autorisées en illégal, mais la conduite doit rester réaliste.
* Le conducteur doit obligatoirement enregistrer sa scène (REC).
* Il est interdit d’emprunter des sentiers ou zones inaccessibles aux voitures.
* En cas de désynchronisation liée à votre connexion ou PC, vous devez jouer la loose.
* Un REC pourra être exigé en cas de problème.

<h2 align="center">3. RÈGLES GÉNÉRALES DU LÉGAL</h2>

***

{% columns %}
{% column valign="middle" %}

<h4 align="center">Métiers incompatibles avec l’illégal</h4>
{% endcolumn %}

{% column %}
Les joueurs impliqués dans l’illégal ne peuvent pas travailler dans :

* SASP
* Gouvernement
* EMS
* Weazel News
* Cabinet d’avocats
* Dynasty

Changement de voie = wipe obligatoire dans les deux sens.

Exception : un agent du SASP peut être ripoux **uniquement sous dossier validé par le staff** (voir [Police](police.md)).
{% endcolumn %}
{% endcolumns %}

***

{% columns %}
{% column valign="middle" %}

<h4 align="center">Fin des zones safe</h4>
{% endcolumn %}

{% column %}
Il n'y a plus de zone safe : les actions illégales sont possibles partout, y compris autour des postes du SASP, des hôpitaux, des QG, des entreprises et pendant les events.

* S'en prendre au **SASP**, au **Gouvernement** ou aux **EMS** (agents, postes, hôpitaux, véhicules de service) entraîne des **conséquences RP lourdes** : réponse du SASP, passage en [Defcon](defcon.md), dossier fédéral possible (voir [Mort RP, Wipe, Fédéral](mort-rp.md)).
{% endcolumn %}
{% endcolumns %}

***

{% columns %}
{% column valign="middle" %}

<h4 align="center">Règles entreprises</h4>
{% endcolumn %}

{% column %}

* Interdiction d’arnaquer ou mentir sur les factures.
* Interdiction de détourner des achats d’entreprise pour de la revente illégale.
* Un joueur ne peut pas acheter deux MLO : c’est limité à une seule MLO par joueur ou groupe illégal.
* Si votre groupe possède déjà une MLO illégale, vous ne pouvez pas acheter de MLO privée.
* Si vous possédez une MLO privée, votre groupe ne pourra pas avoir de MLO illégale.
* Les MLO sont des maisons mappées avec un intérieur et des portes ouvrables sans point de TP.
  {% endcolumn %}
  {% endcolumns %}

***

{% columns %}
{% column valign="middle" %}

<h4 align="center">Logement</h4>
{% endcolumn %}

{% column %}

* Un logement se paie **par carte** (compte en banque), jamais en espèces.
* Trois formules à la signature : **comptant**, **en plusieurs fois** (25 % d'apport, puis 4, 8 ou 12 échéances avec 10 % de frais) ou **location**.
* En plusieurs fois, trois échéances impayées et le logement est repris.
* Un logement qui n'est pas fini de payer ne peut pas être cédé.
* Seuls les **agents immobiliers** peuvent mettre un logement en location (de 1 à 30 jours). La sous-location n'existe pas.
* Un bail rompu avant la fin rend les jours entiers non consommés, moins 25 % gardés par le bailleur.
{% endcolumn %}
{% endcolumns %}

<h4 align="center">SASP</h4>
{% endcolumn %}

{% column %}
**Véhicules et poursuites**

* REC (enregistrement) obligatoire pour conducteurs et pilotes.
* Maximum 2 véhicules de police par véhicule poursuivi.
* Binôme obligatoire pour moto et hélicoptère.
* Formation obligatoire pour utiliser ces véhicules.
* Deux motos comptent comme un seul véhicule.
* Si un motard chute, poursuite interrompue par son collègue.

**Otages**

* Priorité absolue : survie des otages.
* Interdiction d’ouvrir le feu tant qu’un otage est détenu.
* Exception : exécution d’un otage.
* Tir injustifié pouvant mener à mort RP de l’otage + sanctions.

{% columns %}
{% column valign="middle" %}

#### **Plan mule, récupération ou tir pneu**

{% endcolumn %}

{% column %}
Vous êtes autorisés à effectuer **un seul plan mule, plan de récupération ou plan pneu par scène**. Si ce plan échoue, vous devrez poursuivre et terminer la course-poursuite sans pouvoir mettre en place un nouveau plan ni recevoir d'assistance supplémentaire. Dès qu'un plan (mule, récupération, tir pneu, etc.) est utilisé par la partie illégale au cours d'une scène, la partie SASP est autorisée à répondre par un **plan pneu**, sans sommation (voir aussi Tir pneus).

#### Actions autorisées

Les plans mule, récupération et tir pneu sont autorisés uniquement lors des actions suivantes :

* ATM
* Conteneur
* Go Fast (livraison)
* Bijouterie
* Braquage Fleeca
* Braquage Pacific
* Braquage de pharmacie
* Braquage du casino

#### Actions interdites

Pour toute activité ne figurant pas dans la liste des actions autorisées ci-dessus, les plans mule, récupération et tir pneu sont interdits.
